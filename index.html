Deskmate

Deskmate 是一個只在自己電腦上執行的個人工作與記帳工具。它會在使用者授權後，以唯讀方式讀取使用者自己 Gmail 信箱裡的刷卡通知信，整理成記帳資料。

這個工具僅供開發者本人使用，不對外提供服務。

隱私權政策

Deskmate is a personal desktop tool that runs only on the owner's own computer. With the user's consent it reads card-transaction notification emails from the user's own Gmail inbox (read-only) to build personal expense records. It is for the developer's personal use only. See the Privacy Policy.
