Deskmate 隱私權政策

最後更新：2026-11-25

存取哪些資料

Deskmate 只申請 Gmail 的唯讀權限（https://www.googleapis.com/auth/gmail.readonly），用來讀取使用者自己信箱中的刷卡、消費通知信。它不會寄信、刪信或修改任何郵件。

如何使用資料

讀到的通知信只用來解析消費日期、金額與商家，整理成使用者自己的記帳紀錄。資料不會用於廣告、不會用來訓練 AI 模型，也不會出售。

資料存放在哪裡

Deskmate 只在使用者自己的電腦上執行。Google 授權取得的 refresh token 存在本機的 macOS 鑰匙圈，解析出的記帳資料存在本機。沒有任何伺服器會收到這些資料，也不會分享給任何第三方。

如何撤銷授權

使用者可以隨時到 Google 帳戶的第三方存取權頁面移除 Deskmate 的存取權，並刪除本機的資料。

Google API 服務使用者資料政策

Deskmate 使用從 Google API 取得的資訊時，遵守 Google API Services User Data Policy，包括 Limited Use 規定。

聯絡方式

有任何問題，請透過 GitHub 聯絡開發者。

English summary. Deskmate requests only the read-only Gmail scope (gmail.readonly) to read card-transaction notification emails in the user's own inbox and turn them into personal expense records. It never sends, deletes or modifies email. Data is processed and stored only on the user's own computer (tokens in the macOS Keychain); it is not sent to any server, shared with third parties, sold, used for advertising, or used to train AI models. Users can revoke access at any time at myaccount.google.com/permissions. Deskmate's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
